How review and saving work Evidence → decision → GitHub
01 / Read in context

Inspect the exact source passage, edition, and conditions. Repeated terms may have different meanings.

02 / Record a decision

Accept, reject, request revision, or defer an assertion. Keep editorial wording separate from the source. Acceptance does not publish an ontology concept or determine project applicability.

03 / Save through GitHub

Sign in to your GitHub account, then choose Save to GitHub. The report commits your review directly to dod-bco and confirms the saved file. Your draft stays on this device until that confirmation arrives.

Review notes and drafts sent to GitHub are public. Direct saves record your verified GitHub account alongside the reviewer name. GitHub commit history preserves each saved version. Each revision adds an event, preserving earlier decisions. Conflicting reviews remain flagged until reviewed together.
